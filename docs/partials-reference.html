Partials Reference

This file is the canonical source for the shared header, footer and icon sprite. There is no build step (Node.js is not installed and fetch() of partials fails under file://), so this markup is duplicated into every page. When the chrome changes, edit it here first, then propagate to all pages.

Find every copy by grepping for the guard comment:
SITE HEADER — canonical source  /  SITE FOOTER — canonical source

What you should NOT need to edit per page

  • Active nav link — nav.js sets aria-current="page" from location.pathname.
  • Phone / WhatsApp / email / address — edit assets/js/site.config.js only; ui.js stamps every [data-contact] slot.
  • Copyright year — [data-year] is stamped by JS.
  • External link URLs — [data-link="instagram"] etc. resolve from site.config.js.

Per-page values that DO change

  • <title>, meta[name=description], OG tags, canonical.
  • <body data-brand="..."> — zonixa on zonixa.html, msp on msp-sports.html, absent elsewhere.
  • forms.js is included on contact.html only.

No @import — it serialises requests and degrades under file://. Both brand sheets load on every page: they are scoped by [data-brand], which is what lets both brands render side by side on the homepage.

2 · The <html> js-class flip

<html lang="en" class="no-js">
...
<script>document.documentElement.className =
  document.documentElement.className.replace('no-js','js');</script>

Inline and placed in <head> so it runs before first paint. Reveal animations are scoped to .js, so if JavaScript is unavailable the content is simply visible rather than stuck at opacity: 0.

3 · Icon sprite (inline, immediately after <body>)

Master copy: assets/svg/icons.svg. It is inlined rather than referenced because <use href="icons.svg#id"> is blocked under file://.

4 · Header

<!-- ===== SITE HEADER — canonical source: docs/partials-reference.html ===== -->
<div data-header-sentinel aria-hidden="true"></div>
<header class="header" data-header>
  <div class="container header__inner">
    <a class="header__brand" href="index.html">...</a>
    <button class="nav-toggle" data-nav-toggle aria-expanded="false"
            aria-controls="primary-nav" aria-label="Menu">...</button>
    <nav class="nav" id="primary-nav" data-nav-drawer aria-label="Primary">...</nav>
  </div>
</header>
<div class="nav-scrim" data-nav-scrim></div>

The sentinel sits immediately before the sticky header; an IntersectionObserver watches it to toggle data-stuck, which avoids a scroll listener entirely.

4b · Footer notes

Column titles are <p class="footer__col-title">, deliberately not <h2>. They are labels, not document structure — as headings they appeared as peers of real page sections and cluttered screen-reader heading navigation on every page.

The Explore column's list is wrapped in <nav aria-label="Footer"> so it is exposed as a navigation landmark, distinct from the primary nav in the header.

Every external link carries its real URL in the markup (plus target="_blank" rel="noopener") so it still works with JavaScript disabled. ui.js re-stamps it from site.config.js, which remains the single place to edit a URL — but the markup is never left as a dead href="#".

5 · Scripts (before </body>)

<script defer src="assets/js/site.config.js"></script>
<script defer src="assets/js/nav.js"></script>
<script defer src="assets/js/ui.js"></script>
<script defer src="assets/js/reveal.js"></script>
<script defer src="assets/js/forms.js"></script>  <!-- contact.html only -->
<script defer src="assets/js/main.js"></script>   <!-- always last -->

Classic scripts, not modules — <script type="module"> is blocked under file://. defer preserves order and keeps all of it off the critical rendering path.

6 · Link rules

Always relative with an explicit .html (href="zonixa.html"). Never root-relative (href="/zonixa") — under file:// that resolves to the drive root and breaks every link.

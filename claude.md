# CLAUDE.md

## Project

This is a modern website for **Panwar Knitwear**, a knitwear manufacturer based in Ludhiana, Punjab.

Reference website:
https://panwarknitwear.com/

## Design

The website should feel:

* Premium
* Modern
* Clean
* Professional
* Fashion-focused
* Trustworthy

Use strong typography, high-quality product imagery, generous spacing, subtle animations, and a polished visual hierarchy.

## Brands

Panwar Knitwear has two main brands:

**ZONIXA**

* T-shirts
* Hoodies
* Sweatshirts
* Winter wear

**MSP Sports**

* Track pants
* Lowers
* Shorts
* Nikkar
* Capri
* Sportswear

Keep the two brands visually and contextually distinct.

## Development Rules

* Make the website fully responsive.
* Prioritize mobile, tablet, and desktop layouts.
* Use reusable components.
* Keep code clean and modular.
* Avoid unnecessary dependencies.
* Use semantic HTML and accessible UI.
* Optimize images and page performance.
* Use subtle, professional animations.
* Do not fabricate company information, statistics, certifications, clients, awards, or other facts.

## Reference

Use the Panwar Knitwear website as a visual and structural reference, but create a polished modern implementation rather than blindly copying it.

Before making major changes, inspect the existing project and understand its structure.

Always check for build errors and responsive issues after making changes.
